# User provisioning and account management

## IT Service Desk Ticket Handling
`Hello IT Team, this is Bob Wilson from the Finance department.
I would like to request a role change for John Doe (jdoe).
Please add him to the Finance Group and remove him from the Sales Team Group.”`

## Ticket Resolution
1. Reviewed ticket details:
- Requester
- Target user
- Requested access changes

2. Updated group membership:
- Added user to **Finance Group**
- Removed user from **Sales Team Group**
3. Added resolution notes

4. Marked ticket as **Resolved**
- resolved_at timestamp automatically set

## Resolution Message
`Hi Bob,
I’ve processed your request for John Doe (jdoe).
He has been added to the Finance Group and removed from the Sales Team Group.
Please let me know if updates are needed to his title, department, or manager.`
